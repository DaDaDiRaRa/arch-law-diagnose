🏗️ 건축 법규 자동 진단

주소와 건물 정보만 입력하면 건폐율·용적률·높이·주차 법규를 즉시 확인

사내 전용 서비스

접속 방법

http://172.16.0.120:5173

사내 네트워크(Wi-Fi 포함)에 연결된 상태에서 위 주소를 브라우저에 입력하세요.

⚠ 외부망(VPN 미연결)에서는 접속되지 않습니다.

사용 방법

1

대지 주소 입력

검색창에 주소를 입력하고 자동완성 목록에서 선택합니다.
예: 서울특별시 강남구 테헤란로 152

2

건물 정보 입력

건축물 용도, 대지면적, 건축면적, 연면적, 층수, 건물 높이를 입력합니다.
용도지역은 자동으로 조회되므로 보통 비워두어도 됩니다.

3

법규 진단 시작 클릭

파란색 [법규 진단 시작] 버튼을 클릭합니다.
약 3~10초 후 결과가 나타납니다.

4

결과 확인

종합 판정(🟢 적합 / 🟡 주의 / 🔴 부적합)과 항목별 상세 내용을 확인합니다.

입력 항목 설명

항목 필수 설명 예시
대지 주소 필수 도로명 또는 지번 주소. 검색 후 목록에서 선택 강남구 테헤란로 152
건축물 용도 필수 계획 중인 건물의 주용도 선택 업무시설, 공동주택 등
용도지역 선택 비워두면 주소 기반으로 자동 조회.

진단 항목

📐

건폐율

건축면적 ÷ 대지면적. 용도지역별 상한선과 비교합니다.
예: 일반상업지역 60% 이하

📊

용적률

연면적 ÷ 대지면적. 용도지역별 상한선과 비교합니다.
예: 일반상업지역 800% 이하

📏

높이·일조

도로사선·일조사선·절대높이 제한을 확인합니다.
전면도로 폭을 입력하면 더 정확한 결과를 얻을 수 있습니다.

🚗

주차

용도·연면적 기준 법정 주차 대수와 계획 대수를 비교합니다.

🌿

조경

대지 200㎡ 이상 시 의무 조경면적을 계산합니다.
조경면적을 입력하지 않으면 '확인필요'로 표시됩니다.

🔥

설비·소방

스프링클러·소화전·피난 계단 등 설비·소방 의무 항목을 AI가 판단합니다.

주의사항

참고용 자료입니다 본 서비스의 결과는 검토 보조 도구로, 법적 효력이 없습니다. 실제 인허가 전 반드시 관할 지자체 또는 담당 건축사에게 최종 확인하세요.
용도지역 자동 조회 VWorld API로 용도지역을 자동 조회합니다. 간혹 조회 실패 시 결과가 부정확할 수 있습니다. 용도지역을 알고 있다면 직접 선택하세요.
조례 데이터 범위 현재 주요 시군구 조례가 등록되어 있습니다. 조례가 없는 지역은 상위법(시행령) 기준으로 계산됩니다. 출처 배지에서 확인 가능합니다.
서버 운영 시간 서버가 실행 중인 경우에만 접속 가능합니다. 접속이 안 될 경우 담당자에게 문의하세요.

자주 묻는 질문

접속이 안 됩니다.

사내 네트워크에 연결되어 있는지 확인하세요. 연결되어 있는데도 안 된다면 서버 담당자에게 서버 재시작을 요청하세요.

용도지역이 자동으로 나오지 않습니다.

주소 조회 서비스(VWorld) 응답 지연이 원인일 수 있습니다. 용도지역을 직접 선택하거나 잠시 후 다시 시도하세요.

결과가 🔴 부적합인데 실제로는 허가가 날 것 같습니다.

본 서비스는 기본 법규 기준으로 계산합니다. 특례·완화 규정, 지구단위계획 등 예외 조항은 반영되지 않을 수 있습니다. 반드시 담당 건축사와 확인하세요.

설비·소방 항목의 확신도가 낮습니다.

설비·소방 항목은 AI가 판단하므로 다른 항목보다 불확실성이 높습니다. 참고용으로만 활용하고 전문가 검토를 받으세요.

조례 뱃지(🏛 조례)가 표시되지 않습니다.

해당 시군구 조례가 아직 등록되지 않아 상위법 기준을 적용한 것입니다. 조례 등록을 요청하려면 담당자에게 문의하세요.
